# Performance Review Reminder Bot — Project Overview

## What Is This?

A web application that automates the **performance review feedback process** within a company. A **Talent Manager** is responsible for a pool of employees and their performance reviews. The system ensures that before an employee's scheduled review, their teammates are reminded to submit feedback, and the Talent Manager is alerted about any missing submissions.

## Problem Statement

In many teams, performance reviews happen on a set schedule, but collecting peer feedback is a manual, error-prone process. Talent Managers forget to request it, teammates forget to submit it, and deadlines slip.

This bot solves that by:

- Automatically notifying team members when their peer's review is approaching
- Tracking who has and hasn't submitted feedback
- Alerting the Talent Manager about overdue feedback

## Key Scenario (Example)

> **Tom** has a performance review scheduled for March 15.  
> His teammates — Alice, Bob, and Carol — should provide feedback to Tom's Talent Manager, **Bill**.  
> Starting **14 days** before the review date, the system sends daily reminders to Alice, Bob, and Carol.  
> If any of them haven't submitted feedback by **3 days** before the review, Bill gets a notification listing who is late.

## Project Goal

Deliver a **working study application** where at least **90% of the code is generated by AI tools**. The human acts mainly as reviewer and decision maker.

## Scope

| In Scope | Out of Scope |
|---|---|
| Admin page: employee & teammate management (CRUD) | Real authentication (login/password) |
| Performance review scheduling | Integration with HR systems |
| Notification engine (fake email — stored in DB, visible in UI) | Real email delivery |
| Talent Manager dashboard (missing feedback alerts) | Mobile app |
| Seed data for demo purposes | Advanced reporting / analytics |
| Two roles: Talent Manager and Employee | Multi-tenant / multi-company support |

## Tech Stack

| Layer | Choice | Why |
|---|---|---|
| UI | **Blazor Server** | Single project, real-time UI, fits C#/.NET skill set |
| Language | **C# 14 / .NET 9** | Latest stable, matches repo instructions |
| Database | **SQLite + EF Core** | Zero config, file-based, ideal for study project |
| Email | **Fake (log to DB/UI)** | No SMTP setup needed; notifications viewable in app |
| Auth | **Seed-based roles (no login)** | User role switchable via UI dropdown — simplest for demo |
| Background jobs | **Hosted Service** | Built-in `IHostedService` for periodic reminder checks |

## User Roles

| Role | What they can do |
|---|---|
| **Talent Manager** | Manage employees and teams via Admin page. Schedule reviews. View dashboard with feedback status and overdue alerts. |
| **Employee** | View own upcoming reviews, submit feedback for peers, see notification history. |

Role is switched via a dropdown in the header (no login screen). Seed data pre-populates users for each role.
