## Project Overview

**Goal:** Deliver a working application where at least 90% of the code is generated by AI tools, with human oversight for quality and architectural decisions.

### Key Features
- Employee and department management
- Performance review scheduling and tracking
- Feedback submission and tracking
- Automated daily reminder service (simulated)
- Admin dashboard and reporting
- Missing feedback identification

### Technology Stack
- .NET 8 (LTS)
- Blazor Server
- Entity Framework Core 8
- SQLite
- xUnit for testing
- Bootstrap 5 for UI styling

### Architecture
- **Simplified layered architecture:** Blazor UI → Services → Data (DbContext)
- Domain entities separated from services
- Direct DbContext usage (no repository pattern)
- No CQRS, MediatR, or Unit of Work abstractions
- Focus on simplicity, readability, and production quality

## Architecture Principles

### Why This Architecture?
- **No CQRS:** Application complexity doesn't warrant it (YAGNI)
- **No Repository Pattern:** DbContext already provides necessary abstraction
- **No MediatR:** Direct service calls are simpler and more maintainable
- **No Generic Repository:** Specific methods are more explicit and easier to understand
- **Simplified Layers:** Three clear layers with single responsibility

### Folder Structure (Planned)
```
PerformanceReviewReminder/
├── Pages/              # Blazor pages (.razor)
├── Components/         # Reusable Blazor components
├── Layouts/           # MainLayout, AdminLayout
├── Services/          # Business logic services
├── Data/              # ApplicationDbContext and migrations
├── Models/            # Domain entities
├── wwwroot/           # Static files
├── Program.cs
└── appsettings.json

PerformanceReviewReminder.Tests/
├── Services/          # Service layer unit tests
└── Helpers/           # Test helpers and fixtures
```
