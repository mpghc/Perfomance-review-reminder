PROJECT OVERVIEW
================================================================================

Goal: Build an AI-driven performance review reminder system with 90%+ 
      AI-generated code

Tech Stack:
  - .NET 8 (LTS)
  - Blazor Server
  - EF Core 8
  - SQLite
  - xUnit
  - Bootstrap

Architecture:
  - Three-layer: UI → Services → Data
  - Simplified (no CQRS, no MediatR, no generic repositories)
  - Direct EF Core usage in services
  - Transactional multi-entity updates

Key Features:
  - Employee Management (CRUD)
  - Performance Review Scheduling
  - Feedback Collection
  - Automated Daily Reminders ⭐
  - Admin Dashboard
  - Missing Feedback Reports
